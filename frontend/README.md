# Frontend: CS Toolboxes

หน้าแคตตาล็อกเครื่องมือใช้ Next.js App Router, TypeScript และ Tailwind CSS ขณะนี้ใช้รายการเครื่องมือภายในเพื่อให้พัฒนาหน้าและเครื่องมือได้ก่อนเชื่อม SSO

## เชื่อม backend

1. เปิด frontend ที่ `http://localhost:3237`
2. รายการภายในตอนนี้มีเครื่องมือลดขนาดรูปภาพและเปรียบเทียบไฟล์ข้อความ คลิกการ์ดเพื่อเปิดเครื่องมือ
3. รัน backend และ frontend แยกกันด้วย `pnpm dev:backend` และ `pnpm dev:frontend` จาก root workspace

Migration `20261002164500_seed_image_compressor_tool` เพิ่มรายการ “ลดขนาดรูปภาพ” ให้ตาราง `tools`; ใช้ `pnpm --dir backend exec prisma migrate deploy` จาก root เพื่อเตรียมข้อมูลฐานข้อมูลสำหรับการเชื่อม API ในขั้นถัดไป

การค้นหาและกรองหมวดหมู่ทำในหน้าเว็บ ขณะนี้ไม่ได้เรียก API รายการเครื่องมือ จึงไม่ต้องเข้าสู่ระบบและไม่มีการ redirect ไป callback SSO; การเชื่อมฐานข้อมูลและ SSO จะทำภายหลังเมื่อระบบส่วนอื่นพร้อม

## เครื่องมือแปลงเลขฐานพร้อมวิธีทำ

เปิดจากการ์ดในหน้าแรกที่ `/tools/number-base-converter` รองรับฐาน 2, 8, 10 และ 16 จำนวนเต็ม เศษส่วน และค่าติดลบ ใช้ BigInt เพื่อคำนวณโดยไม่สูญเสียความแม่นยำ จำกัดอินพุต 64 หลัก และแสดงทศนิยมได้สูงสุด 20 หลักต่อการแปลง พร้อมแสดงการกระจายค่าตามหลัก ตารางหารซ้ำ และตารางคูณเศษส่วน การคำนวณทั้งหมดเกิดในเบราว์เซอร์และไม่เรียก backend

## Hash & Crypto Toolbox

เปิดจากการ์ดในหน้าแรกที่ `/tools/hash-crypto-toolbox` มี SHA-1 (legacy), SHA-256/384/512, Base64 สำหรับข้อความ UTF-8 และ AES-256-GCM เข้ารหัส/ถอดรหัสข้อความผ่าน Web Crypto โดย derive key จาก passphrase ด้วย PBKDF2-SHA-256 (600,000 รอบ) และสุ่ม salt/IV ทุกครั้ง รองรับข้อความไม่เกิน 1 MB และทำงานเฉพาะในเบราว์เซอร์ ไม่ส่งข้อมูลไป backend; MD5 ไม่รวมในเครื่องมือนี้เพราะ Web Crypto ไม่รองรับและเป็นอัลกอริทึมเก่าที่ไม่ควรใช้ปกป้องข้อมูล

## เครื่องมือลดขนาดรูปภาพ

เปิดจากการ์ดในหน้าแรกที่ `/tools/image-compressor` เครื่องมือนี้รับ JPG, PNG และ WebP ไม่เกิน 25 MB แปลงเป็น WebP หรือ JPG ปรับคุณภาพได้ และย่อด้านที่ยาวที่สุดไม่เกิน 2,560 px การบีบอัดทำในเบราว์เซอร์และดาวน์โหลดกลับมายังอุปกรณ์ ขณะนี้หน้าเว็บยังไม่ส่งไฟล์ไปเก็บประวัติ จนกว่าจะเชื่อม session/token จาก Core Hub SSO ส่วน backend มี API สำหรับเก็บต้นฉบับและผลลัพธ์ใน Docker volume อายุ 30 วัน

## เครื่องมือเปรียบเทียบไฟล์

เปิดที่ `/tools/file-comparison` รองรับ TXT, MD, CSV, JSON และไฟล์ข้อความ/โค้ดทั่วไป ขนาดไม่เกิน 1 MB ต่อไฟล์และ 2,500 บรรทัดต่อฝั่ง ประมวลผลในเบราว์เซอร์และไม่อัปโหลดไฟล์ มีโหมดวางข้อความ สลับฝั่ง ล้างข้อมูล และแสดงบรรทัดที่เพิ่ม ลบ หรือเปลี่ยน

## แปลง PDF เป็น Word

เปิดที่ `/tools/pdf-to-word` รองรับ PDF ที่มีข้อความเลือกคัดลอกได้ ขนาดไม่เกิน 25 MB และไม่เกิน 200 หน้า ดึงข้อความและลำดับบรรทัดเพื่อสร้างไฟล์ Word (.docx) โดยทำงานในเบราว์เซอร์ ไม่อัปโหลดไฟล์ ไม่รักษารูปภาพ ตาราง หรือการจัดหน้า และไม่รองรับ PDF สแกนภาพ/เข้ารหัสหรือ OCR
